# Sidereal: Git Graph, Log & Worktrees

Free Git graph, log and file history for VS Code with worktrees and submodules. No account, no ads, no telemetry.

[Install from the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=zglass.sidereal)

This repository holds Sidereal's issue tracker, discussions, changelog and images. The extension's source code is private.
